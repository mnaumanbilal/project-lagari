# Lagari — Glossary

| Term | Definition |
|------|------------|
| **Lagari** | Luxury fragrance brand; artisanal impressions of iconic designer perfumes. |
| **Impression** | Lagari product positioned as an alternative to a named designer fragrance (e.g. Desert Noir ↔ Louis Vuitton Ombre Nomade). |
| **Designer inspiration** | Original designer fragrance name stored as metafield for search, filters, and AI matcher (FR-5). |
| **COD** | Cash on Delivery — primary checkout model for Pakistan; minimal registration. |
| **RTO** | Return to Origin — failed delivery; tracked in customer risk profile. |
| **Scent pyramid** | Top / heart / base notes visualized on product experience. |
| **Symphonic color morphing** | UI background tokens shift based on fragrance profile (light vs dark scents). |
| **Session** | Analytics unit; ends after 30 minutes idle (FR-4). |
| **Net revenue** | Gross sales − discounts − cancelled/returned orders. |
| **AOV** | Average order value = net revenue ÷ processed orders. |
| **Live activity feed** | Real-time admin stream (cart adds, chatbot product hits, low stock) via SSE/WebSocket. |
| **Phase 1 catalog** | Fragrance only: For Men, For Women, Unisex, All. |
| **Future categories** | Non-fragrance (leather, wallets) — schema extensibility only; out of MVP scope. |
